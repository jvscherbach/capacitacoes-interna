# ADR-001 — Stack e escopo do MVP

- **Status:** Parcialmente substituída pela ADR-003 (itens 1, 3 e 4)
- **Data:** 2026-10-23

## Contexto
MVP individual, a ser construído e demonstrado em um único encontro, sem credenciais ou dados reais.

## Decisões
1. **Python + FastAPI** para a API (documentação automática, validação com Pydantic).
2. **React + Vite** para a interface.
3. **SQLAlchemy + SQLite** (arquivo local) para persistência; PostgreSQL documentado como evolução via `DATABASE_URL`.
4. **pytest** para testes de API; frontend validado por build e fluxo manual.
5. **Sem login/autenticação** no MVP.
6. **Inscrição como entidade própria** (`inscricao`), pois carrega status e data de conclusão; "capacitação" no domínio = curso + turma.
7. **Indicadores calculados por consulta ao banco**, nunca armazenados.
8. **Git/GitHub operados por João**: o Claude Code não executa commit/push; propõe mensagens de commit.

## Consequências
- Menos risco de estourar o tempo; login, Docker, Kubernetes e Vercel ficam como evoluções.
- Qualquer mudança nestas decisões exige novo ADR (ADR-002, ...).
