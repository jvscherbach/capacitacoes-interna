# ADR-002 — Padrão visual do frontend

- **Status:** Aceita
- **Data:** 2026-10-23

## Contexto
O usuário definiu uma imagem de referência (`docs/design/referencia-ui.png`) como padrão de design do frontend.

## Decisão
1. O frontend segue o guia de `docs/DESIGN.md`: sidebar + área principal, cartões brancos arredondados, acento roxo/turquesa, chips pastel e barras de progresso.
2. **CSS puro com variáveis** (tokens) em vez de biblioteca de UI; ícones via `lucide-react`; fonte Inter com fallback do sistema.
3. A referência vale apenas como estilo/layout; sem reproduzir marca, textos ou recursos inexistentes no MVP (IA, caixa de entrada, calendário).
4. Situação da turma (“Vagas abertas / Quase lotada / Lotada”) é **derivada no frontend** de `vagas_ocupadas / vagas`; nenhuma alteração de API ou banco.

## Consequências
- A S2 passa a incluir critérios de aceite visual; o escopo funcional não muda (3 sprints mantidas).
- O estilo deve ser entregue sem comprometer o gate funcional: se faltar tempo, priorizar fluxo completo e tokens/layout base antes de refinamentos.
