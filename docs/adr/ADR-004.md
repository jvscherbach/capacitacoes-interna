# ADR-004 — Configuração de deploy na Vercel (services)

- **Status:** Proposta (aguarda confirmação do usuário sobre nomes de serviços, rotas públicas e persistência)
- **Data:** 2026-10-23

## Contexto
O MVP rodava apenas localmente (ADR-001 e CLAUDE.md excluíam deploy). O usuário pediu a configuração do repositório para deploy na Vercel como projeto com múltiplos serviços (frontend Vite + backend Express).

## Decisão
1. `vercel.json` na raiz com `services`: `backend` (`root: backend`, `framework: express`) e `frontend` (`root: frontend`, `framework: vite`).
2. Rewrites públicos, do mais específico ao mais genérico: `/api/(.*)` → `backend`; `/(.*)` → `frontend`. Só esses dois serviços recebem tráfego público.
3. A Vercel entrega o caminho original ao serviço (sem remover `/api`); as rotas do Express já são `/api/...`. Foi adicionado `GET /api/health` (o `/health` antigo continua para uso local).
4. Sem *bindings*: o frontend é uma SPA estática e chama a API pelo navegador (`/api`, mesma origem); nenhum serviço chama outro no servidor.
5. Frontend: URL da API é `/api` em produção (build) e `http://localhost:8000/api` em desenvolvimento; `VITE_API_URL` continua sobrescrevendo.
6. Backend: `server.js` exporta o app (`export default app`) e só chama `listen` fora da Vercel; na Vercel o banco SQLite fica em `/tmp/capacitacoes.db` (único local gravável).

## Consequências e riscos
- **Persistência:** `/tmp` na Vercel é efêmero e por instância. Os dados **não persistem** de forma confiável entre execuções frias nem são compartilhados entre instâncias. Serve como demonstração, não como "banco persistente" (RNF02). Persistência real exige banco externo (ex.: PostgreSQL gerenciado), o que troca a camada `db.js` e pede novo ADR.
- `better-sqlite3` é módulo nativo; não foi possível confirmar nas docs nem testar o build na Vercel (NÃO TESTADO).
- A entrada do serviço Express foi deixada para detecção automática (`backend/src/server.js`); as docs consultadas não especificam nomes de entrypoint.
- CLAUDE.md dizia "sem deploy no MVP": este ADR é a exceção explícita pedida pelo usuário.
